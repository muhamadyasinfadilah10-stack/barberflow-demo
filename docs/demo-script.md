# Skenario Demo 5 Menit untuk Owner

**Persiapan:** data seed terisi, login sebagai owner, HP sudah terdaftar di test number, dashboard terbuka di laptop.

| Menit | Langkah | Poin yang disampaikan |
|---|---|---|
| 0:00 | Tunjukkan dashboard kosong hari ini | Satu layar: booking, antrean, omzet, komisi |
| 0:30 | Dari HP kirim `BOOKING`, pilih Potong rambut → Hari ini → jam → kapster | Pelanggan booking sendiri 24 jam, tanpa admin membalas chat |
| 1:30 | Kirim `BOOKING` lagi dengan jam & kapster sama | Sistem menolak bentrok dan menawarkan slot lain |
| 2:00 | Refresh dashboard: booking muncul. Kirim `JADWAL`, lalu `BATAL` | Pelanggan bisa cek dan batalkan sendiri |
| 2:30 | Buka **Antrean**, tambah 1 pelanggan walk-in | Walk-in dan booking terkelola di satu tempat |
| 3:15 | Selesaikan booking (QRIS) dan walk-in (Tunai) | Komisi kapster terhitung otomatis |
| 3:45 | Buka **Komisi** dan **Laporan**, klik Export CSV | Rekap harian/mingguan siap, tidak perlu hitung manual |
| 4:15 | **Buka & Tutup**: tekan Tutup, tunjukkan preview, tekan Kirim ke WhatsApp | Laporan terkirim ke owner dengan 1 tombol, gratis |
| 4:45 | Login sebagai kapster di HP | Kapster hanya melihat jadwal dan komisinya sendiri |

**Penutup:** tanyakan jumlah chat booking per hari saat ini, lalu tawarkan pilot 2 minggu.
